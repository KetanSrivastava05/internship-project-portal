# 📋 User Stories for Internship & Project Management Portal

This document outlines 25 key user stories for the Internship & Project Management Portal, categorized by user roles. These stories guide the development and testing of features.

## 🎓 Student
1.  **Registration:** As a *Student*, I want to *register using my college email* so that *I can access the internship portal.*
2.  **View Internships:** As a *Student*, I want to *browse and filter available internships* so that *I can find opportunities relevant to my field.*
3.  **Apply for Internship:** As a *Student*, I want to *submit my application and resume* to a specific internship so that *I can be considered for the role.*
4.  **Track Application:** As a *Student*, I want to *view the status of my applications (Applied/Shortlisted/Rejected)* so that *I can stay informed.*
5.  **Submit Weekly Report:** As a *Student*, I want to *submit weekly progress reports* so that *my internal and external mentors can track my work.*
6.  **View Evaluations:** As a *Student*, I want to *see feedback and grades from my mentors* so that *I can improve my performance.*
7.  **Profile Management:** As a *Student*, I want to *update my skills and portfolio* so that *recruiters can see my latest achievements.*

## 🏢 Company / Recruiter
8.  **Post Internship:** As a *Recruiter*, I want to *post new internship openings with detailed descriptions* so that *students can apply.*
9.  **Manage Applications:** As a *Recruiter*, I want to *view a list of applicants and their resumes* so that *I can shortlist suitable candidates.*
10. **Interview Scheduling:** As a *Recruiter*, I want to *update the status of an applicant to 'Interviewed'* so that *the student knows the next steps.*
11. **Final Selection:** As a *Recruiter*, I want to *approve or reject candidates* so that *the hiring process is finalized.*

## 🧑‍🏫 Faculty (Internal Mentor)
12. **View Mentees:** As a *Faculty*, I want to *view the list of students assigned to me* so that *I can manage my mentorship duties.*
13. **Review Reports:** As a *Faculty*, I want to *read and comment on weekly reports* so that *I can provide timely guidance.*
14. **Approve Projects:** As a *Faculty*, I want to *approve project proposals* so that *students can begin their work.*
15. **Grading:** As a *Faculty*, I want to *assign grades to reports and final projects* so that *academic assessment is completed.*

## 🏭 External Mentor
16. **Industry Guidance:** As an *External Mentor*, I want to *view student progress reports* so that *I can ensure their work meets industry standards.*
17. **Feedback:** As an *External Mentor*, I want to *provide specific feedback on technical implementation* so that *the project quality improves.*

## 📊 TPO (Training & Placement Officer)
18. **Dashboard Analytics:** As a *TPO*, I want to *view charts showing placement statistics* so that *I can analyze the success rate of the batch.*
19. **Export Data:** As a *TPO*, I want to *download reports of placed students* so that *I can share data with the college administration.*
20. **Broadcast Notifications:** As a *TPO*, I want to *send announcements to all students* so that *they are aware of upcoming deadlines and drives.*

## 🔐 System Admin & College Admin
21. **User Management:** As a *System Admin*, I want to *create and manage user accounts and roles* so that *access control is maintained.*
22. **Configure Settings:** As a *System Admin*, I want to *configure system-wide settings (e.g., academic year, deadlines)* so that *the portal operates correctly for the current session.*
23. **Faculty Allocation:** As a *College Admin*, I want to *assign faculty mentors to students in bulk* so that *the mentorship process is organized.*
24. **Audit Logs:** As a *System Admin*, I want to *view activity logs* so that *I can monitor system usage and security.*

## 🧪 Evaluator
25. **Project Evaluation:** As an *Evaluator*, I want to *access project documentation and code submissions* so that *I can conduct the final viva/assessment.*
